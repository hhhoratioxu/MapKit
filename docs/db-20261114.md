# MapKit DB 調試版

`4.6.1-db.20261114`，2026-11-14。

此版本供 Loon 安裝、對照和回報。原生 Mac「地圖」的巴黎衛星 3D 驗收仍未通過。

## 已修正

- 補充地區清單下載遇到網路錯誤時，主請求會繼續前往使用者選定的地區。既有快取可繼續供合成程式使用。
- ETag 回應標頭的不同大小寫均可識別。
- 發出條件式下載前先檢查快取是否能使用，讓空白或損壞的快取可以重新下載。
- 快取預檢直接驗證 protobuf 資料，減少建立完整訊息物件的配置。

顯示名稱為 `MapKit`。沿用現有 16 個選項及預設值，包括 `Satellite2D=CN`、`Satellite3D=XX` 和 `Flyover=XX`。

## 驗證

完整自動測試通過 55 項。下載錯誤的回歸案例驗證主請求的美區選擇及立體圖層得以保留。正式版與開發版入口另以離線環境核對 Loon、Surge、Shadowrocket、Stash、Egern 和 Quantumult X。

同日在這台 Mac 用系統自帶 curl、系統正常憑證驗證及實際 macOS 請求欄位取得美區清單，得到 HTTP 200、69 組圖層和 11 種立體樣式。現有回應腳本合成後保留這些立體樣式，並保留中國大陸衛星底圖。

經使用者同意，曾暫時寫入上述混合資源清單並正常重開原生 Maps。巴黎鐵塔的畫面仍是地名和空白地面。測試已結束，原生資源快取已核對還原為測試前的完整位元組。這份資料尚未證明原生渲染器實際採用了所有新增圖層。

這台 macOS 27.3 的原生配置請求曾拒絕 Loon 的憑證鏈。原生通道和實際影像顯示仍需繼續處理。此版本的腳本修正及自動測試結果各自按上述範圍解讀。

## 安裝

在 Loon 匯入本版的固定版本插件，再沿用自己的 16 項設定。插件引用同一標籤下的腳本。

[MapKit.lpx](https://raw.githubusercontent.com/hhhoratioxu/MapKit/db-20261114/Loon/script/MapKit.lpx)

Release 同時附上三份執行腳本、授權文件、SHA-256 校驗檔及 ZIP。原生快取、節點資料、憑證、請求細節和測試視窗截圖保存在本機。
